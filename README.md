# tora-typesetter

מנוע עימוד דטרמיניסטי לספרים תורניים, הנבנה מחדש ב-Rust.

## עקרונות יסוד

- Rust הוא מקור האמת היחיד לחישוב ולבחירות העימוד.
- אין מדידות DOM או החלטות reflow ב-WebView.
- גאומטריית המנוע תיוצג ב-fixed-point; אין להשתמש ב-floating point בהחלטות layout.
- כל החלטה משמעותית תהיה ניתנת להסבר, לשחזור ולביקורת עצמאית.
- פרופילי legacy נשמרים מבודדים; אין למזג אלגוריתמים או baselines של V21 ו-V23.

## מבנה התחלתי

- `crates/model` — מודל מקור ותוכן.
- `crates/geometry` — טיפוסי גאומטריה ויחידות.
- `crates/engine-core` — חוזי הליבה והחלטות העימוד.
- `xtask` — משימות פיתוח, סריקה ואימות.

זהו שלד workspace בלבד. לא הוטמעה עדיין לוגיקת עימוד, מדידת גופנים או שבירת שורות.

## פיתוח

השתמשו ב-toolchain המוצמד ב-`rust-toolchain.toml`.

```sh
cargo fmt --all -- --check
cargo test --workspace --locked
cargo build --workspace --locked --release
```
